ИНСТРУКЦИЯ: КАК СОБРАТЬ APK ОНЛАЙН ЗА 3 МИНУТЫ (БЕЗ ПРОГРАММ НА ПК)
===================================================================

В этом архиве находится полный готовый проект Android-приложения "Nissan CVT Diag Pro"
для классического синего адаптера ELM327 v1.5 (Bluetooth 2.0 SPP).

Внутри архива уже настроен робот автосборки (файл .github/workflows/build_apk.yml).
Вам нужно просто загрузить файлы из этой папки на бесплатный сайт GitHub,
и сервер сам соберет для вас установочный файл .APK!

ШАГ 1: Распакуйте этот ZIP-архив в любую папку на вашем компьютере или телефоне.
(Важно: внутри есть папка .github — она тоже нужна!).

ШАГ 2: Зайдите на сайт https://github.com (войдите или зарегистрируйтесь бесплатно).
Нажмите кнопку "+" в правом верхнем углу -> "New repository" (Новый репозиторий).
- В поле "Repository name" напишите: nissan-cvt
- Чуть ниже поставьте галочку "Add a README file"
- Нажмите зеленую кнопку "Create repository" внизу.

ШАГ 3: На открывшейся странице нажмите кнопку "Add file" -> "Upload files".
Перетащите ВСЕ файлы и папки из распакованного архива (папки app, .github и файлы build.gradle, settings.gradle, gradle.properties) в окно браузера.
Дождитесь загрузки полосок и нажмите зеленую кнопку "Commit changes" внизу.

ШАГ 4: Скачайте готовый APK!
1. В верхнем меню вашей страницы на GitHub нажмите вкладку "Actions" (со значком треугольника).
2. Вы увидите желтый кружок "Build Nissan CVT Diag APK" — подождите 2-3 минуты, пока он станет ЗЕЛЕНОЙ ГАЛОЧКОЙ.
3. Нажмите на надпись "Build Nissan CVT Diag APK", прокрутите страницу в самый низ до раздела "Artifacts".
4. Нажмите на "Nissan-CVT-Diag-Pro-APK" — на ваш компьютер или телефон скачается готовый установочный файл app-debug.apk!
